# Pokemon Battle Game (Java)

A Java program that simulates a two-player Pokémon card battle game using stacks.

## Documentation 
[**Click Here To See Javadoc**](https://bobbymcd422.github.io/PokemonBattle-Java/)
## Features
- Reads card data from an input file
- Deals cards between two players
- Compares cards by power and multiplier
- Tracks winner, total plays, and ending card counts
- Includes sample input files for testing

## Project Structure
- `src/` - Java source files
- `data/` - sample input files
- `doc/` - generated Javadocs

## How to Run
1. Compile the Java files in `src/`
2. Run `BattleDemoMcDonald`
3. Enter one of the sample file names when prompted
